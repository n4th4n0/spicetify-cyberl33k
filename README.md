# Cyberl33k — Spicetify Playback Bar Animation

Animated **Cyberl33k** character for the Spotify playback bar using **Spicetify**.

Cyberl33k follows Spotify's current playback position with a smooth linear movement.

<p align="center">
  <img src="./cyberl33k.gif" alt="Cyberl33k animated preview" width="128">
</p>

## Features

- Animated Cyberl33k character
- Smoothly follows Spotify's playback progress
- Uses Spotify's native playback-bar movement
- Does not block clicking or dragging the progress bar
- Animated WebM used by the extension
- Available directly through Spicetify Marketplace
- Automatically pauses and resumes with Spotify playback
